# Архитектура FinLock MDM

## Схема

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  Mac магазина   │     │  FinLock API     │     │  MicroMDM       │
│  Configurator 2 │────▶│  (наш сервер)    │────▶│  (MDM Apple)    │
│  enrollment     │     │  CRM + команды   │     │  APNs push      │
└─────────────────┘     └────────┬─────────┘     └────────┬────────┘
                                 │                        │
                                 ▼                        ▼
                        ┌─────────────────┐     ┌─────────────────┐
                        │  Admin панель   │     │  iPhone клиента │
                        │  lock/unlock    │     │  supervised     │
                        └─────────────────┘     └─────────────────┘
```

## Компоненты

| Компонент | Роль |
|-----------|------|
| **Apple Business Manager** | Реестр устройств организации, DEP |
| **MicroMDM** | Открытый MDM-сервер, шлёт команды Apple |
| **FinLock API** | Устройства, клиенты, lock/unlock, журнал |
| **Admin UI** | Менеджер магазина |
| **Configurator 2** | Ручной supervised enrollment на Mac |

## Идентификаторы устройства

| Поле | Использование |
|------|----------------|
| **Serial Number** | Главный ID для MDM (обязателен) |
| **UDID** | После enrollment — для команд |
| **IMEI** | Учёт, поиск в CRM, не для lock |
| **Model** | iPhone 14, 15… |

## MDM-команды (через MicroMDM)

| Действие | Apple-команда | Условие |
|----------|---------------|---------|
| Заблокировать экран | `DeviceLock` + сообщение | Supervised / enrolled |
| Разблокировать | `ClearPasscode` / снять lock | После оплаты |
| Сброс PIN | `ClearPasscode` | Supervised, политика разрешает |
| Статус online | Last check-in MDM | Периодический опрос |
| Lost Mode message | `EnableLostMode` | Альтернатива lock с текстом |

## Статусы в FinLock

| Статус | Описание |
|--------|----------|
| `pending` | Зарегистрирован, ещё не enrolled |
| `active` | Enrolled, рассрочка идёт |
| `locked` | Заблокирован (просрочка) |
| `paid_off` | Рассрочка закрыта, MDM снят |
| `offline` | Не выходил на связь > N часов |
| `tamper` | Попытка снять профиль / сброс |
