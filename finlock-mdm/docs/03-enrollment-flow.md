# День продажи — enrollment iPhone в рассрочку

## Менеджер магазина (5–10 минут)

### До передачи телефона клиенту

1. Распаковать iPhone, включить, пройти начальный setup **до экрана Wi‑Fi** (или полный setup на языке клиента).  
2. Подключить iPhone к **Mac** USB.  
3. Открыть **Apple Configurator 2** → выбрать iPhone → **Prepare** (если первый раз) или убедиться что MDM профиль активен.  
4. Завершить setup на iPhone, клиент входит в **свой Apple ID** (не магазина).  
5. Открыть **FinLock Admin** → «Добавить устройство»:
   - Serial, IMEI, модель  
   - ФИО клиента, телефон  
   - Сумма рассрочки, дата следующего платежа  
6. Распечатать/подписать приложение: клиент согласен с MDM до конца рассрочки.  
7. Выдать телефон.

### При просрочке

1. FinLock → найти клиента / IMEI / serial.  
2. «Заблокировать» → ввести текст: «Оплатите 12 000 сом до …»  
3. iPhone показывает экран блокировки с сообщением.  
4. После оплаты → «Разблокировать».

### Закрытие рассрочки

1. Все платежи внесены.  
2. FinLock → «Снять MDM» / «Рассрочка закрыта».  
3. На iPhone: Settings → General → VPN & Device Management → удалить профиль (или remote remove через MDM).

## Если клиент «забыл PIN»

Supervised + политика MDM → команда **ClearPasscode** из FinLock (кнопка «Сбросить PIN» — только для enrolled supervised).

## Что отслеживается

| Событие | Действие FinLock |
|---------|------------------|
| iPhone вышел online | `last_seen` обновлён |
| Долго offline | Статус `offline`, алерт менеджеру |
| Попытка удалить MDM | `tamper`, опционально auto-lock |
| Просрочка платежа | Автоблок (фаза 1) |

## Локатор

Apple MDM location — отдельная команда, требует разрешения. Asia MDM «слабо в локаторе» — типично: iOS ограничивает фоновую геолокацию. Для MVP **не обещать GPS** — фокус на lock + online/offline.
