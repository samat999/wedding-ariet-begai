# Как устроен Asia MDM — предположения

По видео и типичной архитектуре рассрочки iPhone.

## Не одно «приложение», а несколько слоёв

| Слой | Видно клиенту? | Что делает |
|------|----------------|------------|
| **MDM-профиль** | Настройки → VPN и управление устройством | Lock, PIN, политики, supervised |
| **Configurator / DEP** | Нет | Enrollment при продаже и после прошивки |
| **Agent-приложение** | Может быть иконка на экране | Check-in, статус online, иногда локатор |
| **Apple Account / hidden iCloud** | Настройки → Аккаунт Apple | Activation Lock под контролем системы |
| **Веб-панель** | Только у магазина | IMEI, toggle lock, журнал |

## Ставят ли «приложуху поверх»?

**Скорее да, но не как единственную защиту.**

### Вариант A — только MDM-профиль (60%)
- Без иконки на домашнем экране
- Управление через сервер + Configurator
- Lock = системная команда Apple DeviceLock

### Вариант B — MDM + agent app (30%, похоже на Asia)
- Магазин ставит **корпоративное приложение** через MDM (mandatory install)
- Приложение: периодический check-in, online/offline, иногда геолокация
- **Блокировка всё равно через MDM**, не через UI приложения
- Приложение может показывать сообщение «оплатите» до системного lock

### Вариант C — профиль + скрытый iCloud (10% дополнительно)
- Отдельный сервис (на видео что-то вроде hidden cloud)
- Привязка Activation Lock к учётке организации
- После прошивки — экран активации, без пароля системы не обойти

## Что видно на твоём видео

1. **Configurator на Mac** — точно MDM enrollment, не просто app store app  
2. **Панель с IMEI + зелёные toggle** — их CRM/MDM backend (как наш FinLock)  
3. **Экран «Аккаунт Apple»** — слой iCloud / Apple ID, не обычное приложение  
4. **После прошивки Hello + setup** — если нет DEP, всё слетает; с DEP — снова MDM

## Вывод для FinLock

Минимум для рассрочки:
1. MDM-профиль (MicroMDM + ABM)  
2. Admin-панель (FinLock)  
3. Optional: agent app для check-in (фаза 2)

Agent app **не заменяет** MDM — без профиля его можно удалить после сброса.

## FinLock roadmap
